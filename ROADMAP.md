# План развития tgfarm — два канала, непрерывный режим

Дата: 27.10.2026. Основание: аудит кода (`review/01-architecture.md`,
`review/02-security.md`, `review/03-reliability.md`, `review/04-product-docs.md`,
`review/05-research-agents.md`), реальные замеры на живой базе и проверка
площадок через API.

## 1. Где ферма находится сейчас

| Параметр | Факт |
|---|---|
| Каналы | 2 активных, оба `catch_all`: Дзен `zen_misc_ru`, ВК `vk_misc_ru` |
| Тон | сухая ирония, одна шутка на пост, без кликбейта |
| Дзен | профиль Chrome на месте, публикация через веб-редактор, потолок 1 пост / 10 мин |
| ВК | токен группы рабочий, `wall.post` работает, потолок ~50 постов / сутки |
| Темп | Дзен 120/сутки (12 мин), ВК 48/сутки (30 мин) → в сумме пост каждые ~7 мин |
| Источники | 251 запись → 67 уникальных коллекторов (184 копии схлопнуты) |
| LLM | **работает**: unorouter.com, бесплатные Gemini-Flash/Mistral, проверено живыми вызовами |
| Фактический режим | `TGFARM_MODE=live`, генерация идёт через бесплатные модели unorouter |
| Тесты | 350 зелёных, 0 падений (было 4 падения при 315) |
| ruff | 40 замечаний, все — унаследованные; новых нет |

### Что уже исправлено в этом проходе

1. **Публикация в ВК стала полноценной**: `platform: vk` больше не притворяется
   Телеграмом, у него свой лимит 15 000 символов, свой путь `wall.post` и запись
   в `crosspost_logs`.
2. **Двойная отправка закрыта**: пост забирается из очереди атомарным
   `UPDATE ... WHERE status='scheduled'`, cycle и 5-минутный тик больше не могут
   отправить один пост дважды.
3. **Застрявшие посты возвращаются**: `publishing` старше 15 минут уходит обратно
   в очередь с записью причины, а не висит вечно.
4. **Тесты больше не публикуют**: сеть и все платные ключи заблокированы в
   `conftest.py`. Именно этого не хватало — один тест успел реально отправить
   пост в группу ВК.
5. **`tgfarm doctor` перестал врать**: проверка LLM делает настоящий запрос,
   а не смотрит на наличие ключа.
6. **Интервальный темп**: `cadence.mode: interval` держит паузу между постами
   одного канала и растягивает дневную квоту на 24 часа.
7. **Юмор в персоне**: тон и правила стиля заданы так, чтобы шутка была одна,
   не в заголовке и не про людей.
8. **Дубли источников схлопнуты**: 251 запись реестра содержала 184 копии одних
   и тех же запросов. Теперь 67 уникальных коллекторов, а копии автоматически
   выключаются в базе — одна новость больше не надувает `heat` двести раз.
9. **Дзен перестал принимать шаблонные черновики**: послабление по минимальной
   длине для офлайн-композера больше не действует на Дзене. 200 символов вместо
   900 — это не статья, а именно то, за что площадка режет показы.
10. **Ротация моделей**: `LLM_MODEL` принимает список через запятую. 429 и
   «модель не найдена» переводят вызов на следующего кандидата, рабочий
   запоминается, а модель без `response_format` получает повтор без JSON-режима.
   Бесплатный тариф живёт именно на этом механизме.
11. **Бесплатная цепочка OpenRouter** прописана в `.env`: 6 моделей с суффиксом
   `:free` и две дешёвые платные (Qwen3.5-Flash, DeepSeek V4.1 Flash) как
   страховка. Проверить их с этого хоста нельзя — 403; первая же попытка после
   включения VPN покажет в `tgfarm doctor`, кто ответил.
12. **Few-shot из лучших постов**: S4 подмешивает в промпт два лучших
   опубликованных поста канала (по средней оценке гейтов) с прямым запретом
   копировать содержание — перенимать интонацию и юмор.
13. **Режим ручного одобрения**: `TGFARM_APPROVAL_REQUIRED=true` останавливает
   автопубликацию — посты копятся в `gated` до кнопки в панели. Для Дзена на
   старте это защита от дерекомендации за автогенерацию.
14. **Критик по рубрике**: тон-гейт переписан в редакционную рубрику из шести
   пунктов (факты, юмор не в заголовке и не про людей, шаблонные зачины, вода,
   кликбейт, читаемость) — это и есть writer → critic → rewriter из разведки.
15. **Разделение ролей моделей**: `LLM_CRITIC_MODEL` позволяет писать дешёвой
   моделью, а судить более сильной; по умолчанию цепочка общая.
16. **Алерты оператору**: watchdog и `/api/status` несут список проблем (нет
   публикаций N часов, застрявший publishing, упавший цикл, падающая
   генерация); настраивается `ALERT_NO_PUBLISH_HOURS`.
17. **Стадия maintenance** в каждом цикле: TTL для зависших forming-кластеров,
   ретеншн raw_items (90 дней) и журналов (30 дней), WAL-checkpoint. До этого
   база росла без остановки, а 3 800 мёртвых кластеров пересчитывались зря.
18. **Ротация переживает 503**: перегруженная модель больше не топит весь
   провайдер — вызов уходит к следующему кандидату. DeepSeek V4.1 Flash
   (согласие дано) встал первым в цепочку, углы Дзена и ВК разведены
   (Дзен — разборы, ВК — короткие новости).

## 2. Что мешает прямо сейчас

**Провайдер найден — LLM работает.** Рабочий эндпоинт: `https://api.unorouter.com/v1`
(OpenAI-совместимый, доступен с этого IP). Цепочка бесплатных моделей в
`LLM_MODEL` проверена живыми вызовами через клиент фермы:

| Модель | Замер | Комментарий |
|---|---|---|
| `gemini-3-flash:free` | 4.1 с, валидный JSON | основная |
| `gemini-3.1-flash-lite:free` | 1.4 с, валидный JSON | самая быстрая, вторая в цепочке |
| `gemini-3.6-flash:free` | 5.6 с, JSON в markdown-заборе — парсер фермы переваривает | |
| `gemini-3.5-flash-lite:free` | 2.3 с, JSON в заборе | |
| `gemini-2.5-flash:free` | отвечает, но жёсткий 1 запрос/мин | |
| `mistral-small-3.2:free` | 3.7 с, валидный JSON | хук кликбейтит — гейты отфильтруют |

Ограничение free-тира: **1 запрос в минуту на модель**. Ротация из 8 кандидатов
это закрывает; при пачке запросов 429 уходят на следующую модель автоматически.

Модели из выдачи пользователя (`glm-4:free`, `mistral-7b-instruct:free`,
`granite-4.0-micro:free`, `gpt-oss-20b:free`, семейство DeepSeek) требуют
одноразового согласия провайдера в браузере: `https://unorouter.com/consents?model=<id>`.
Стоит кликнуть для `deepseek-v4.1-flash-1017:free` — по разведке это сильнейший
русский текст в списке; после согласия добавить его первым в `LLM_MODEL`.

OpenRouter остаётся недоступным с этого IP (403, гео-блок) — не блокер, но
`LLM_PROXY` держим как запасной вход.

## 3. Лимиты площадок, из которых считается темп

| Площадка | Потолок | Что происходит при превышении | Вывод |
|---|---|---|---|
| ВК (`wall.post`, токен группы) | ~50 постов/сутки | `Flood control`, ошибка 214 | 48/сутки, шаг ~30 мин |
| Дзен (веб-редактор) | 1 пост / 10 мин, дальше модерация | не 429, а показ только подписчикам | 120/сутки, шаг ~12 мин |
| Вместе | ~168 постов/сутки | — | средний шаг ~7 мин |

Требование «пост каждые 5–10 минут» выполняется суммой двух площадок, а не
частотой одной. Гнать 288 постов в сутки в одну площадку нельзя: ВК упрётся в
flood control, Дзен — в модерацию.

## 4. Фазы развития

### Фаза 0 — оживить генерацию (блокирует всё)

- [ ] Дать рабочий LLM-доступ (VPN / `LLM_PROXY` / другой ключ).
- [ ] Прогнать `tgfarm doctor` — все проверки `ok`, кроме Telegram (он не нужен).
- [ ] Один контролируемый цикл: `tgfarm cycle`, разобрать 3 поста вручную,
      сравнить с тем, что писала ферма до этого.
- [ ] Проверить, что в группе ВК нет тестового поста `t / b` — его мог отправить
      тест до починки; API группового токена стену не читает, удалять вручную.

### Фаза 1 — качество текста при непрерывном темпе

1. **Критик-редактор (writer → critic → rewriter).** Сейчас S5 умеет один
   целевой рерайт по причине гейта. Добавить отдельного критика с рубрикой
   «смысл, факты, юмор, отсутствие воды» и жёстким порогом: два провала —
   отклонение. Ожидаемый эффект по литературе — +20% к качеству при +30% токенов.
2. ~~Few-shot из собственных лучших постов.~~ Сделано (по средней оценке
   гейтов вместо ER — он появляется позже). Дальше: holdout 10% трафика и
   guardrail-метрика разнообразия, чтобы оптимизация не схлопнулась в шаблон —
   за шаблонность Дзен наказывает.
3. ~~Починить длину.~~ Сделано для Дзена: офлайн-послабление больше не
   применяется к `platform: dzen`. Осталось развести его по форматам, чтобы
   `flash` не резался минимумом канала.
4. ~~Разобраться с дублями источников.~~ Сделано: дедуп на загрузке конфига
   и выключение исчезнувших строк в базе. Осталось дедупить одну статью под
   разными id внутри Google News (канонический URL).
5. **Кластеры-зомби.** ~3 800 кластеров в `ready`, полезны единицы. Ввести
   `status='stale'` и TTL-джоб, иначе каждый цикл перебирает мёртвое.

### Фаза 2 — площадки и охват

1. **Картинки в ВК.** Сейчас ВК получает только текст. Нужен трёхшаговый
   `photos.getWallUploadServer → upload → save` и `attachments`. Обложки уже
   рисуются для Дзена — использовать их же.
2. **Встроенные фото в Дзене** уже работают (`article_images`), но лимит
   `ARTICLE_IMAGE_MAX_MB` стоит проверить на реальных статьях.
3. **Разные углы для двух каналов.** Один кластер уходит в оба канала: Дзен —
   разбор, ВК — короткая новость с иронией. Уже поддержано `angle_weights`,
   нужно развести значения сильнее и мерить, что заходит.
4. **Метрики Дзена → выбор часа.** `s12_learning` уже сдвигает веса; при
   непрерывном темпе час не важен, важна тема и хук. Переключить обучение на
   «тема × угол × формат».

### Фаза 3 — автономность и самодиагностика

1. ~~Алерты оператору.~~ Ядро сделано: список проблем в watchdog и
   `/api/status`. Осталась доставка наружу (бот/почта) — см. Горизонт 2.
2. ~~Самолечение провайдера.~~ 5xx и 429 уходят в ротацию моделей, отчёт в
   `llm_stats`; провайдер паркуется только при мёртвом ключе.
3. **Автоотключение источников.** Есть `failures`/`idle_streak`, но нет
   автоматического `enabled: false` после серии отказов — добавить с возвратом
   через сутки.
4. **Ежедневный отчёт сам себе.** Раз в сутки: сколько сгенерировано,
   сколько отклонено и почему, что зашло. Это же — вход для правки промптов.

## 5. Агенты, которых стоит добавить

Не «ещё один фреймворк», а роли с измеримой пользой:

| Агент | Что делает | Модель | Стоимость |
|---|---|---|---|
| Редактор-критик | оценивает пост по рубрике, возвращает правки | дешёвая | ~+30% к токенам поста |
| Фактчекер | сверяет цифры с источником и веб-поиском | средняя | 1 вызов на пост |
| Скаут тем | ищет сюжеты вне RSS (поиск, тренды) | дешёвая | 10–20 вызовов/сутки |
| Аналитик | недельный разбор метрик → предложения по промптам | дорогая, раз в неделю | копейки |
| Юморист | переписывает одну фразу в сухую иронию | дешёвая | по желанию |

Проверенные паттерны: Self-Refine (writer → critic → rewriter), RAG по
собственным лучшим постам, bandit по углам и форматам. Внешние фреймворки
(LangGraph, CrewAI) для двух каналов не нужны — существующий конвейер уже
разделяет роли по стадиям.

## 6. Экономика

При ~168 постах в сутки и ~3 000 токенов на пост (черновик + фактчек + критик):

| Модель | Цена за 1M (вход/выход) | В месяц при 168 постах/сутки |
|---|---|---|
| Qwen3.5-Flash | $0.065 / $0.26 | ~$3–5 |
| DeepSeek V4.1 Flash | $0.15 / $0.60 | ~$7–12 |
| Gemini 2.5 Flash | ~$0.30 / $1.20 | ~$15–25 |

Дешёвая модель + критик почти всегда выгоднее дорогой модели без критика.
Бесплатные тарифы OpenRouter для JSON-режима не годятся: лимиты рвут конвейер.
