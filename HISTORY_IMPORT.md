# Импорт старых публикаций в TgFarm

Импортёр заполняет архив уже опубликованных материалов, чтобы память и «досье темы» учитывали посты, созданные до запуска TgFarm. Он **не публикует** содержимое на площадки и не создаёт задачи публикации.

## Форматы

- **Telegram Desktop**: экспорт чатов в JSON, включающий объект `chats.list[].messages[]`.
- **VK**: JSON-ответ стены с `response.items[]`, либо общий JSON со списком `posts`/`items`.
- **Дзен и другие экспорты**: общий JSON или CSV с колонками вроде `title`, `text`, `published_at`, `url`, `external_id`. Формат с нестандартными колонками можно сначала преобразовать в такой CSV.

Для Telegram Desktop в окне экспорта выберите JSON и включите сообщения. Для крупных экспортов рекомендуется сначала скопировать только нужный JSON-файл в отдельную папку, сохранив исходный экспорт.

## Безопасный процесс

Сначала проверьте ID канала командой `tgfarm channels`. Это ID канала TgFarm, а не обязательно ID группы на платформе.

### Telegram напрямую через уже настроенную сессию

Если авторизация пользовательской сессии TgFarm уже настроена, можно читать историю напрямую без экспорта:

```bash
tgfarm telegram chats
tgfarm history-import-telegram @public_channel --channel my_telegram_channel --limit 1000
```

Укажите username, ссылку `t.me/...` или доступный аккаунту ID чата. Команда использует существующую read-only-сессию и ограничивает запрос диапазоном 1–5000 сообщений. При заданном лимите выбирается старейшая часть доступной истории, сообщения без текста пропускаются. Сначала выполните предпросмотр, затем добавьте `--apply`, когда отчёт устроит. Для закрытого канала ссылка на пост не придумывается.


**1. Предпросмотр без записи:**

```bash
tgfarm history-import "D:/exports/telegram/result.json" --channel my_telegram_channel
```

Для CSV/JSON из ВК:

```bash
tgfarm history-import "./exports/vk-wall.json" --channel my_vk_channel --platform vk
```

**2. Прочитайте JSON-отчёт.** Проверьте `planned_imports`, `skipped_duplicates`, `without_date` и первые 10 записей в `sample`. При большом архиве сначала делайте пробный импорт небольшой выгрузки.

**3. Только после проверки включите запись:**

```bash
tgfarm history-import "./exports/history.csv" --channel my_channel --platform dzen --apply
```

Без флага `--apply` база не изменяется. Повторный импорт того же файла пропускает записи с совпадающим внешним ID или нормализованным текстом. Для контента с повторяющимся текстом, но разным смыслом, лучше добавить даты/ID и проверить предпросмотр.

## Что сохраняется

Запись создаётся со статусом `published`, датой оригинальной публикации (если присутствует), меткой `history_import` и происхождением в `sources`: платформа, внешний ID, имя канала и исходный URL. Метрики просмотров/реакций не выдумываются и не импортируются этим инструментом. Записи без даты импортируются, но отчёт отдельно их считает.

Сейчас это локальный импорт файла, а не автоматическая синхронизация с авторизованными аккаунтами. Прямое чтение всей истории из площадки требует отдельного адаптера с явными разрешениями и ограничениями API. Никогда не передавайте экспорт или сессию аккаунта в публичный issue/PR.
