# Центр площадок TgFarm

Панель «Площадки» — единая точка управления уже подключёнными каналами и будущими интеграциями.

## Что означает переключатель

- **Включена**: новые отправки на эту площадку разрешены, если настроены нужные credentials и сама платформа принимает запросы.
- **Выключена**: новые отправки блокируются; запланированные записи не удаляются и остаются в очереди. После включения они снова смогут отправиться.
- **Нужна настройка**: маршрут поддерживается кодом, но в файле .env отсутствуют обязательные ключи или не найден профиль.
- **В плане интеграций**: приоритет выбран, но рабочего адаптера пока нет. Эта метка не включает публикацию и не создаёт fake-success статусы.

Переключатель не обрывает запрос, который уже передан внешней площадке. Уже начатая отправка может завершиться. Неизвестный результат по-прежнему требует ручной сверки, автоматический дубль не запускается.

## Рабочие интеграции сейчас

| Площадка | Роль | Где задаётся подключение |
|---|---|---|
| Telegram | Основная публикация | TELEGRAM_BOT_TOKEN и целевой канал |
| ВКонтакте | Основные посты и кросспост | VK_ACCESS_TOKEN, VK_GROUP_ID |
| Дзен | Основные статьи через браузерный профиль | Авторизованный профиль браузера Дзена |
| MAX | Кросспост | MAX_ACCESS_TOKEN, MAX_CHANNEL_ID |
| X | Кросспост | X_BEARER_TOKEN, X_USER_ID; права токена нужно проверить отдельно |

Наличие ключей не считается проверкой авторизации. Используй контролируемый live smoke-test с одной тестовой публикацией на каждой площадке перед ростом объёма.

## Каталог следующих интеграций

### Следующая очередь: P1

1. **Reddit**. Посты под конкретный subreddit, заголовок и тело; добавить выбор communities, лимиты, флаги self-promotion и правила конкретного сообщества.
2. **YouTube**. Загрузка видео и Shorts, название, описание, теги и обложка. Нужен отдельный видео-конвейер и OAuth.
3. **TikTok**. Короткие вертикальные видео; потребуются субтитры, адаптация ролика, OAuth и допуск к Content Posting API.
4. **Instagram**. Reels, изображения и карусели. API-публикация зависит от типа аккаунта, прав Meta и доступов приложения.
5. **Одноклассники**. Отдельная версия контента для российской аудитории, после проверки доступного официального API.
6. **RUTUBE**. Видео и клипы, после подтверждения актуального официального способа загрузки.

### Вторая очередь: P2

- **Threads**: короткие сообщения, визуальные заметки.
- **Facebook Pages**: публикации на страницах; это не универсальный постинг в личный профиль.
- **LinkedIn**: экспертные материалы, B2B и публикации организации. Права API и версия endpoint требуют проверки при реализации.
- **Pinterest**: вертикальные карточки/пины, ведущие на первоисточник или статью.
- **Bluesky**: короткие посты и карточки ссылок через AT Protocol.
- **Discord**: анонсы в принадлежащие владельцу серверы через бота или webhook.
- **vc.ru**, **Хабр**: отдельные статьи, а не простое копирование поста.
- **TenChat**: деловые публикации с отдельной редактурой.

### Третья очередь: P3

- **Mastodon**: федеративные сети, настройки серверов отличаются.
- **WhatsApp Channels**: проверять отдельно. WhatsApp Business Messaging API не следует путать с API управления Channels.
- **Medium**: статьи; прежде реализации необходимо подтвердить доступный API создания публикаций.
- **Пикабу**, **Tumblr**: нишевые посты и визуальные сообщества.
- **Twitch**: анонсы трансляций и клипы.
- **Snapchat**: вертикальные видео при наличии доступа к нужному продукту публикации.
- **WeChat/Weixin**, **Douyin**, **RedNote/Xiaohongshu**: региональные интеграции; потребуют отдельной стратегии, локализации и проверки доступов.

## Почему приоритет такой

Для русскоязычной аудитории разумно сначала довести VK, Telegram, MAX, Дзен и видео-маршруты YouTube/TikTok/RUTUBE. Для международного охвата уместны Reddit, YouTube, TikTok, Instagram, Threads, Facebook Pages, LinkedIn, Pinterest и Bluesky. Reddit особенно полезен, но стратегия должна быть нативной для subreddit: тематические посты и прозрачное участие, а не массовая рассылка одного рекламного текста.

Это стартовый приоритет, а не универсальный рейтинг популярности. Приоритет стоит менять под географию, тематику, аудиторию и фактические результаты конкретных каналов.

## Как добавить новый адаптер правильно

1. Проверить актуальную официальную документацию, разрешения приложения и правила публикации.
2. Реализовать самостоятельный адаптер с форматированием, медиа, ограничениями, rate-limit и классификацией ошибок.
3. Сохранить remote ID/URL и идемпотентность. После timeout нельзя повторять отправку вслепую.
4. Добавить offline-тесты и тесты ошибок; новая площадка остаётся в режиме «план» до завершения проверки.
5. Выполнить одну контролируемую live-публикацию, сверить её вручную, затем постепенно наращивать объём.

Состояние каталога хранится в config/platforms.yaml. Секреты и токены в этот файл не записываются: держи их в .env или секрет-хранилище.
