Досье темы

история → обновления → продолжение

Собирает хронологию постов, свежие материалы и старые утверждения, которые стоит перепроверить. Расхождения чисел помечаются как возможные, а не как доказанная ошибка.

Введи тему и нажми «Собрать досье», чтобы соединить старые публикации со свежими источниками.

COMMUNITY SCOUT · REDDIT

Найти своё сообщество

Поиск subreddit по теме, сверка доступных правил и подготовка отдельного текста под выбранное сообщество. Поиск ничего не публикует.

r/
Для поиска нужны настройки Reddit OAuth с правом чтения. Live-публикация здесь не запускается автоматически.

FEEDBACK LOOP · REDDIT

Что реально сработало

Собираем score, комментарии и долю голосов из доступного Reddit Data API. Рейтинг Scout постепенно учитывает фактический результат, а не только описание сообщества.
